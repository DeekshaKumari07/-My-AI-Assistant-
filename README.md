# 🤖 My AI Assistant

## 📌 Project Overview
My AI Assistant is a modern AI-powered web application that allows users to interact with an intelligent assistant. It can answer questions, summarize text, generate creative stories, and provide study tips using the Google Gemini API.

---

## ✨ Features

- Answer Questions
- Text Summarization
- Story Generation
- Study Tips
- Responsive Dark Theme UI
- Feedback Buttons
- Flask Backend Integration
- Google Gemini API Integration

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- Google Gemini API

## 🚀 How to Run

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open your browser and visit:

```
http://127.0.0.1:5000
```
